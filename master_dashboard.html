Growfather Gummy Production SOP (from SharePoint — Edition 1)

Source: SharePoint · "Gummy Depositing SOP.docx" + Recipe Cards. Approver: COO Chris Capurso. Terpenes = Abstrax (per-flavor recipe card). Dashboard COGS values take precedence over the 2024 recipe cards.
  • Equipment: Truffly Made depositor (8 pistons, 5 heat pads, nozzle/side/rear/front heaters), induction burner + double boiler per pot, thermometer/alarm, homogenizer, molds, sheet pans, bun racks.
  • Materials/pot: 10 kg gummy mix (1 Melt-to-Make box), THC oil (use Melt-to-Make calculator for dose — potency varies per oil batch), MCT oil, Abstrax flavor per recipe card, silicone + oil spray.
  • Prep: assemble + oil depositor (nozzles 195°, hopper 180°); double boiler 2–3" water on burner #6; load 10 kg pucks; thermometer alarm 165°; spray 42 molds w/ MCT.
  • Operation: melt to 165° (burner 12 → 6 + 10 min), skim bubbles (or weight fails testing), add THC + Abstrax flavor per recipe card, homogenize 30s (or mixer 3 min), deposit into sugared molds, level to flush.
  • Demold/cure: set 3–5 hrs (cold room ≤69°), press out onto sugar bin, fluff + coat, sift, single-layer cure overnight, then pack 10s into Growfather tins → packaging stage.

Naming & Batch ID Conventions

Standard (06/2026): every unit carries five layers — External (Metrc label) · Internal (Distru pick/assembly) · SKU (stable system key) · Lot/Batch (run trace) · Expiration (printed shelf date). The SKU never changes per batch — the Lot code carries the date, which keeps sales history, velocity, and forecasting intact. Applies to The Growfather, Little Leaf Labs Moonrock, Octane, and Dr. Zodiak's.

The Five-Layer Naming Standard

LayerPurposeFormatExample
ExternalLabel / Metrc / legal — what printsMost-recent approved Metrc Item Name (Metrc Item Export)1.2g (H) White Widow x Strawberry Cough Moonrock Infused Preroll XL
InternalDistru pick-pack & assembliesBrand | Weight | Subcategory | Flavor/Strain | IHSGF | 1.2g | Infused Preroll | White Widow x Strawberry Cough | H

Lot / BatchTraces the production run (immutable)YYMM + run letter = production/test month2605A (1st May-2026 run; B = 2nd)
ExpirationPrinted shelf date — editable on relabeltest date + 6 mo → extend 12/18 mo on relabel2026-11 → 2027-05 (lot stays 2605A)
Why the date is NOT in the SKU: a dated SKU makes every batch a new "product," fragmenting sales history and breaking per-SKU velocity/forecast. The SKU identifies what it is; the Lot identifies which run. Expiration is derived (test+6mo) and bumped on relabel — the lot code never moves, so traceability is preserved while the printed date floats.

Production Intelligence — Batch Status & Forecast Rules

Batch status definitions
  • WIP Batch — manufacturing / assembly / testing pending / testing submitted. Active production inventory.
  • Label Batch — testing PASSED, awaiting labeling / packaging / final release. NOT finished goods — remains an Active Production Batch and must appear on the Production, Active Batch, and Inventory Forecast views. Do not remove from production reporting.
  • Ready For Sale (RFS) — tested, labeled, packaged, released to inventory. Only RFS is sellable inventory.
Label batch naming standard — Brand | Product Line | Strain/Flavor | Batch # | Mfg Date. e.g. Growfather | Sour Diesel | Moonrock Preroll | Batch 2605-01. Flag batches missing Strain/Flavor/Product Name as Production Data Errors.
Triggers: create a WIP batch when Weeks Remaining ≤ 3 (with material + labor requirements + expected completion); submit testing at ≈ 1 week of cover so results return before depletion.
Priority order: 1) Unit velocity · 2) Weeks remaining · 3) Gross-profit contribution. A 1,500-unit/mo preroll outranks a 150-unit/mo vape even if the vape earns more revenue.
Daily exec questions: Which SKUs run out first? Which need WIP this week? Which to submit for testing? Which await labels? Which active batches are stuck? What to schedule next? What inventory risk exists in the next 6 weeks?
